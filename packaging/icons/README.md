# Icons

Omega Notch uses the Omega family mark (a geometric Ω) in the `notch` palette: amber on dark brown. The
SVGs here are generated by the Omega brand repo; change the shape or the palette there, not here.

- `omega-notch.svg`: the app icon (rounded square, used for the menu entry, Settings and notifications).
- `omega-notch-tray.svg`: the bare mark with no background, for a tray (not used yet).
- `omega-notch-dev.svg`: the app icon with a DEV band across the bottom, for debug builds (not used yet).

`install.sh` puts `omega-notch.svg` and the PNGs in `hicolor/` into `~/.local/share/icons/hicolor`, under
the icon name `omega-notch`.

## Turning the SVGs into this app's icons

Needs `rsvg-convert` (librsvg).

```sh
for n in 16 22 24 32 48 64 128 256 512; do
  mkdir -p packaging/icons/hicolor/${n}x${n}/apps
  rsvg-convert -w $n -h $n packaging/icons/omega-notch.svg -o packaging/icons/hicolor/${n}x${n}/apps/omega-notch.png
done
rsvg-convert -w 224 -h 224 packaging/icons/omega-notch.svg -o docs/assets/icon.png   # the README
```
